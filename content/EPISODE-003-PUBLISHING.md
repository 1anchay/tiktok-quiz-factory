# Episode 003 publishing notes

## TikTok sound target

Use **Sky — Playboi Carti** from TikTok's official music library when publishing.

Suggested mix:
- Original video audio: 100% so the quiz SFX stay audible.
- Added TikTok sound: about 15–20%.
- Slide the song so a strong beat lands around **2.0 seconds**, when the hook changes from **«ОСТОРОЖНО 18+»** to **«ДА ЛАДНО 😏 ЭТО ВСЕГО ЛИШЬ ВИКТОРИНА»**.

The exported MP4 intentionally does **not** contain a copied commercial MP3. This keeps the render clean and lets TikTok apply the licensed in-app sound.
