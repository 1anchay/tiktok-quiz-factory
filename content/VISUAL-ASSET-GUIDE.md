# Visual Asset Policy

All new publishable episodes should be **image-first**.

## Do
- Use four attractive square images per game.
- Keep every image readable on a phone.
- Use a single object or clear scene per clue.
- Prefer original AI-generated artwork or clearly licensed generic source photography.
- Use visual motifs that hint at a game without copying its exact logo, UI or promotional artwork.
- Keep a consistent cinematic 1:1 composition with strong subject separation.
- Save clue assets as JPG/WebP around 720×720.

## Avoid
- Text baked into clue images.
- Game logos.
- Screenshots ripped from games.
- Cover art and promotional posters.
- Tiny details that only work on desktop.
- Four clues that instantly give the answer away.

## Difficulty pattern
- Level 1: familiar and fair.
- Level 2: recognizable after 2–3 clues.
- Level 3: requires game knowledge.
- Level 4: expert.
- BOSS: hard but solvable; answer stays hidden.

## Pacing
A clue should appear roughly once per second. After the fourth clue, leave a short thinking pause, then show the answer. The next game follows immediately after the answer beat.
